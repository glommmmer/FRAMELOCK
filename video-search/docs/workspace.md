# 工作区维护

整理日期：2026-11-22。工作区仅以 `video-search` 作为当前项目；旧课堂项目独立归档到 `archive/course-seek`。

## 当前项目

- `server/`、`web/`、`deploy/`、`scripts/`：源码、部署和运行脚本。
- `docs/planning/`：方案与开发清单；`docs/experiments/`：早期样本和评测设计。历史记录不冒充最终验收。
- `samples/beverage/fixture-v1/`：冻结的七段静音开发样本、标注及十二条查询。`samples/beverage/` 下其余目录为原视频抽帧与人工复核材料。
- `tools/ffmpeg/win-x64/`：本机 FFmpeg，附原发行包许可证和说明。脚本也支持 `FFMPEG_PATH` 和 PATH；换机器需自行准备可执行文件。
- `output/`：真实评测与验收证据，包括历史失败结果；不提交。`api-local.log` 可能仍在写入。
- `.data/`：上传/媒体文件、模型及帧缓存、费用账本、运行配置；不提交。清空模型缓存可能导致重复付费，删除账本会破坏费用控制。
- `web/node_modules/`：本项目自己的依赖目录，已解除对旧前端目录的链接。

运行脚本仍读取工作区根目录 `.env` 的共享云配置，再以项目 `.env` 覆盖。此安排保留原有凭据使用方式，不将密钥搬进文档或源码。
