# 用户使用流程检查

检查日期：2026-11-23。先完成收藏夹功能，再检查创建项目、上传、等待处理、查找、回看、收藏、移动与找回旧结果。下表保留最初检查时的问题；用户随后指定其中六项实施，处理结果如下。

## 本轮处理进展

- 已修复历史搜索恢复：同步原项目、原问题、查找方式与结果；关闭旧订阅并忽略晚到响应，防止切换后被旧结果覆盖。历史记录只读取已有结果，不重新调用模型。
- 已阻止未准备好的搜索：页面禁用并给出上传或查看进度入口；后端创建和重试均检查已发布的视频索引，拒绝无可查视频的请求。部分视频准备好时说明本次范围。
- 历史列表已显示原问题、所属项目、时间、状态及“查看结果”。
- 项目与收藏夹可改名、删除。只允许删除无视频且无未完成上传的空项目，软删除保留历史关联；删除收藏夹将片段移回未分类，不取消收藏、不删除原视频。操作前明确确认规则。
- 收藏显示来源项目，点击可返回所属项目。
- 标准查找无答案时直接提供“多找一轮”和“换个描述”，说明额外等待及可能费用；已通过真实普通/Agent 无答案流程验证。

46 项后端测试通过；实际浏览器验证了原来的历史范围错位修复、空项目按钮、临时项目和收藏夹改名删除、收藏保留及来源跳转，手机宽度 390px 正常。记录见 output/workflow-fixes-check.json。

“刷新后记住当前项目”不在用户本轮选择的六项中，未改。片段导出等产品取舍也仍待讨论。

## 已完成的收藏夹功能

收藏页可新建收藏夹，收藏片段时可选择目标或临时新建；已有收藏可移动到另一个收藏夹或未分类。一个片段对应一条收藏记录，重复收藏可调整归属，不生成重复记录。收藏夹按账号隔离，移动保留视频和时间范围，刷新后保留。

收藏夹首版使用 Flyway V5，当时 43 项后端测试通过。真实浏览器完成创建、指定收藏夹、内联创建、跨夹移动、移回未分类、重复收藏、同名提示、刷新保留与 390px 布局检查。首版证据见 output/favorite-folder-check.json、favorite-folders.png、favorite-save-dialog.png；本轮升级后的 V6 和 46 项测试见上文。
