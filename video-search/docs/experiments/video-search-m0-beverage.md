## 脚本与验证

`scripts/video-search-lab.py`：本地读取媒体元信息，按实际帧时间生成采样清单和联系表，支持 `--start`、`--duration`、`--interval`。依赖 Python 和 Pillow，默认使用已有 `tools/ffmpeg/win-x64/ffmpeg.exe`；不执行网络调用，输出目录存在时拒绝覆盖。

用法：

```powershell
python scripts/video-search-lab.py --id sample01 --input '视频绝对路径.mp4' --interval 5
python scripts/video-search-lab.py --id sample01 --input '视频绝对路径.mp4' --start 10 --duration 12 --interval 0.5
python scripts/test-video-search-lab.py
```

`scripts/build-beverage-fixture.py`：根据这次复核的固定范围构建静音片段和回看页；依赖两条完整视频采样清单。标注属于暂定视觉复核，不是模型预测。再次运行需要选择新的输出版本或先人工处理已有目录。

抽帧集成检查 3 项通过：

1. 使用已知时刻红色变蓝色的合成视频，确认截取后时间与实际颜色对应。
2. 检查截取截止时间、无音轨视频和画面文件与时间清单的一致性。
3. 检查原文件不变、已有输出不被覆盖。

七段输出的时长与设定一致、均无音轨；事件在所属区间内，括区与估计边界一致，查询引用有效。准备过程中修正了输出级 `-t` 使日志多记一帧的问题，改为过滤阶段先截取再记录时间。
